openoms

An open source multi-client order management system.

Install

curl -fsSL https://maxkuttner.github.io/openoms/install.sh | sh
oms database init
oms

Then open http://localhost:3001/cockpit/. Read the script before you pipe it into a shell — it downloads one checksummed binary into ~/.local/bin and stops there. No sudo, nothing started, nothing configured.

oms database init needs a Postgres 16 to talk to. Don't have one? Clone the repo and run docker compose up -d — it brings up exactly the database the defaults assume.

What you get

  • Order routing across multiple brokers, over FIX and REST.
  • A web cockpit compiled into the binary — blotter, positions, connections.
  • Trading tokens scoped to a principal's portfolio grants.
  • Risk checks and order reconciliation on reconnect.
  • A Python client and CLI for everything the API exposes.

Requirements

  • macOS on Apple Silicon, or Linux on x86_64, for the prebuilt binary.
  • Postgres 16.
  • Anything else: build from source — see the readme.
