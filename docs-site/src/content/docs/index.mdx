## Features

<CardGrid>
  <Card title="Multi-broker routing" icon="random">
    Orders routed to Alpaca, Binance, Bybit and Interactive Brokers, over FIX and REST.
  </Card>
  <Card title="Web-based admin UI" icon="laptop">
    Connections, positions and a blotter in the browser, plus a trader UI with a trade ticket.
  </Card>
  <Card title="Control trading access" icon="approve-check">
    Traders and tokens see only the portfolios they are granted.
  </Card>
  <Card title="Risk and reconciliation" icon="warning">
    Pre-trade risk checks, and order reconciliation.
  </Card>
