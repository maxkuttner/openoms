## Install

<Code code="curl -fsSL https://maxkuttner.github.io/openoms/install.sh | sh" lang="sh" />

[Read the script on GitHub](https://github.com/maxkuttner/openoms/blob/main/install.sh) before you pipe it into a shell — it downloads one
checksummed binary into `~/.local/bin`, then offers to run `oms init`. No sudo, nothing
started or configured without asking. Prebuilt for macOS on Apple Silicon and Linux on x86_64; anything else
[builds from source](/openoms/getting-started/#1-install).

## What you get

<CardGrid>
  <Card title="Multi-broker routing" icon="random">
    Orders routed to Alpaca, Binance, Bybit and Interactive Brokers, over FIX and REST.
  </Card>
  <Card title="A cockpit in the binary" icon="laptop">
    Blotter, positions, connections and a trade ticket — served by the OMS itself.
  </Card>
  <Card title="Scoped trading access" icon="approve-check">
    Traders and tokens see only the portfolios they are granted.
  </Card>
  <Card title="Risk and reconciliation" icon="warning">
    Pre-trade risk checks, and order reconciliation whenever a broker reconnects.
  </Card>
</CardGrid>
